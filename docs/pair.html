Auto mit Home Assistant verbinden

Die Daten werden auf diesem Handy verschlüsselt und direkt an dein Auto geschickt.

Mit https. Die Adresse muss für das Auto aus dem Internet erreichbar sein. Home Assistant > dein Profil > Sicherheit > Langlebige Zugriffs-Token. Für Live-Fahrzeugdaten (Tempo, RPM, Temperaturen, Gang) an deine Automation.
Was passiert mit meinen Daten?
  • Ende-zu-Ende verschlüsselt (AES-256-GCM) mit dem Schlüssel, der nur im QR-Code und im Auto liegt.
  • Der Transport erfolgt über ntfy.sh – der Server sieht ausschließlich unentschlüsselbares Ciphertext.
  • Auf diesem Smartphone wird absolut nichts gespeichert oder gecacht.
  • Schaltberechtigungen können niemals vom Handy aktiviert werden, nur im Auto selbst.
